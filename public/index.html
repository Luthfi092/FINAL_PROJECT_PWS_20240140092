API Documentation

POST /api/auth/register — register

POST /api/auth/login — login JWT

POST /api/keys — generate API key dengan JWT

GET /v1/tracks — katalog musik dengan API key

GET /v1/tracks/:id — detail track

GET /v1/artists — artis

GET /v1/genres — genre

GET /v1/stats — statistik

Contoh request

curl -H "x-api-key: mk_live_xxxxxxxxx" "https://DOMAIN.vercel.app/v1/tracks?search=neon&limit=5"
